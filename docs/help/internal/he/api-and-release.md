## תחזוקת חוזי API ממוקדים

המלאי מכיל רישום נתיבים, מטפלים ומקורות. חלק יחסי לקבוצה אינו URL מלא. אמתו קלט, תפקיד JWT ובעלות עסק; גם נתיב ציבורי של עסק דורש הקשר. סנכרנו Go, TypeScript ו-Dart. פרטי לקוח לפי שיטת ביצוע דורשים capability הגדרות `pos_fulfillment_customer_information_supported` ו־`customer_information` בשליחה קבוצתית. שימרו דגל חסר לפי מזהה יציב; false מפורש מכבה אותו. אמתו וכללו אטומית customer_name/customer_phone/delivery_notes/delivery_apt/custom_fields בטביעת האידמפוטנטיות. אצוות נוספות יורשות רק פרטים עקביים; לקוחות מעורבים וחשבונות מפוצלים דוחים החלפה. יצירה קבוצתית אינה שולחת אישורי לקוח לכל שלב, בלי לפגוע באירועי מטבח/צוות או הודעות סטטוס עצמאיות. אין לשלוח הודעות אמיתיות בבדיקות.

<span id="release" />

## בדיקה וקידום אותו ארטיפקט

השתמשו ב-PR אחד ל-develop לכל מאגר, השלימו בדיקות ואמתו ארטיפקט פיתוח קבוע. קידום לייצור אחרי אישור ואימות פיתוח וללא בנייה מחדש מ-main. אין לשנות מיגרציות שהוחלו או .env אמיתי. תעדו גרסאות ויעדי חזרה.

## בדיקת השפעת תיעוד

לכל שינוי התנהגות שייכו יכולות, עדכנו שלוש שפות ותעדו גיבובי מקור. חריג ללא השפעת משתמש דורש סיבה בדוקה. CI דוחה גיבוב ישן, תרגום חסר, משטח לא מסווג וקורפוס AI שונה; בדיקת מטא לבדה אינה אימות מוצר.
