ב־Foody Admin, בחרו את המסעדה ופתחו **תוכנית מועדון → סטודיו Wallet**.

> **יש לאשר זמינות גרסה**
> האפליקציה קיימת במקורות. המדריך אינו מאשר הפצה ציבורית או זמינות בגרסה המותקנת.

## זמינות וגישה

השתמשו בחשבון עם גישה להגדרות המסעדה. שמירת הטיוטה ויצירת כרטיס בדיקה של Apple דורשות הרשאת עריכה. הבדיקה ב־iPhone דורשת תוכנית מועדון ותעודת Apple Pass Type ID עם מפתח תואם שמוגדרים בשרת.

<span id="save-design" />

## שמירת עיצוב פרטי

בחרו צבע רקע וצבע טקסט ל־Apple. בחרו לוגו ותמונת כותרת בפורמט PNG או JPEG, עד 1 מ״ב לקובץ. עברו בין Apple Wallet ל־Google Wallet כדי לבדוק את החיתוך. בחרו **שמירת טיוטה**. אם נשמרה גרסה עדכנית יותר, טענו אותה מחדש לפני ניסיון נוסף.

<span id="apple-test" />

## הוספת כרטיס בדיקה ל־iPhone

בעיצוב השמור בחרו **יצירת כרטיס בדיקה של Apple** ואז **הורדת קובץ ‎.pkpass**. פתחו את הקובץ ב־iPhone ובחרו **הוספה**. בדקו את הלוגו, תמונת הכותרת, הצבעים ואת הכיתוב כרטיס בדיקה. הכרטיס מציג התקדמות להמחשה וקוד QR לדוגמה. אם החתימה אינה זמינה, בדקו את הגדרות החתימה של Apple בסביבה הנוכחית. הלשונית Google מציגה את העיצוב בתצוגה מקדימה.
