ב־Foody Admin בחרו את המסעדה ופתחו **לקוחות ← תוכנית מועדון ← סטודיו Wallet**.

> **יש לאשר זמינות גרסה**
> האפליקציה קיימת במקורות. המדריך אינו מאשר הפצה ציבורית או זמינות בגרסה המותקנת.

## זמינות וגישה

השתמשו בחשבון עם גישה להגדרות המסעדה. שמירה, בדיקה ופרסום דורשים הרשאת עריכה. בדיקת Apple דורשת תוכנית מועדון ותעודת Apple Pass Type ID עם מפתח תואם. בפיילוט ללקוחות יש להפעיל גם את ה־API של Wallet ואת הספק שנבחר בסביבת הבדיקה.

<span id="save-design" />

## שמירת עיצוב פרטי

בחרו צבע רקע וצבע טקסט ל־Apple. בחרו לוגו ותמונת כותרת בפורמט PNG או JPEG, עד 1 מ״ב לקובץ. עברו בין Apple Wallet ל־Google Wallet כדי לבדוק את החיתוך. בחרו **שמירת טיוטה**. אם נשמרה גרסה עדכנית יותר, טענו אותה מחדש לפני ניסיון נוסף.

<span id="apple-test" />

## הוספת כרטיס בדיקה ל־iPhone

בעיצוב השמור בחרו **יצירת כרטיס בדיקה של Apple** ואז **הורדת קובץ ‎.pkpass**. פתחו את הקובץ ב־iPhone ובחרו **הוספה**. בדקו את הלוגו, תמונת הכותרת, הצבעים ואת הכיתוב כרטיס בדיקה. הכרטיס מציג התקדמות להמחשה וקוד QR לדוגמה. אם החתימה אינה זמינה, בדקו את הגדרות החתימה של Apple בסביבה הנוכחית. הלשונית Google מציגה את העיצוב בתצוגה מקדימה.

<span id="publish-design" />

## פרסום עיצוב הכרטיס ושיתוף קישור הצטרפות

הפעילו את תוכנית המועדון של מסעדת הפיילוט. תחת **כרטיס ללקוחות**, בחרו **פרסום עיצוב הכרטיס** כדי להחיל את העיצוב השמור. פרסמו שינויים נוספים כשהם מוכנים. בחרו **העתקת קישור להצטרפות** כדי לשתף את דף המועדון של המסעדה. אם יש התנגשות, טענו מחדש את הסטודיו ובדקו את העיצוב השמור.

<span id="member-card" />

## הצטרפות, הוספת כרטיס אישי ובדיקת צבירה

בטלפון, פתחו את קישור ההצטרפות, התחברו, אשרו את התנאים והצטרפו. ב־iPhone בחרו **הוספת הכרטיס ל־Apple Wallet** ואז **הוספה** ב־Wallet. כאשר Google זמין, כפתור **הוספה ל־Google Wallet** פותח את Google לצורך אישור. הורידו שוב מהחשבון ובדקו את קוד ה־QR ואת ההתקדמות. בצעו הזמנת בדיקה מזכה ושלמו מאותו חשבון. בדקו שההתקדמות בכרטיס תואמת לדף המועדון. בפיילוט קופה שבו מופעלים זיהוי ומכירות מועדון, סרקו את קוד ה־QR האישי ושייכו את החבר לפני אישור התשלום. בהגעה לסף, בדקו את ההטבה באזור המועדון ונסו לממש אותה בתהליך תשלום שהופעל.
