ב־Foody Admin בחרו את המסעדה ופתחו **לקוחות ← תוכנית מועדון ← סטודיו Wallet**.

> **יש לאשר זמינות גרסה**
> האפליקציה קיימת במקורות. המדריך אינו מאשר הפצה ציבורית או זמינות בגרסה המותקנת.

## זמינות וגישה

השתמשו בחשבון עם גישה להגדרות המסעדה. שמירה, בדיקה ופרסום דורשים הרשאת עריכה. בדיקת Apple דורשת תוכנית מועדון ותעודת Apple Pass Type ID עם מפתח תואם. בפיילוט ללקוחות יש להפעיל גם את ה־API של Wallet ואת הספק שנבחר בסביבת הבדיקה.

<span id="save-design" />

## שמירת עיצוב פרטי

בחרו צבע רקע וצבע טקסט ל־Apple. העלו לוגו ובאנר בפורמט PNG, JPEG או WebP, עד 10 מ״ב לקובץ. פתחו **מסגור הבאנר**. בחרו **התמונה כולה** כדי להציג את כל השוליים או **מילוי המסגרת** כדי לחתוך את התמונה. כוונו את הזום וגררו את התמונה בתצוגה המקדימה, או השתמשו במחוונים למיקום אופקי ואנכי. Apple ו-Google חולקים את הגדרות המסגור. כדי לכוון אותם בנפרד, הפעילו **מסגור נפרד ל-Google** בתצוגת Google. ב-Apple אפשר למקם את המונה **מתחת לבאנר** או **על הבאנר**. הטיוטה הפרטית שומרת את קובץ המקור של העלאות חדשות. לבאנר ישן אפשר להעלות מחדש את המקור כדי לערוך ברזולוציה המלאה. כבו את **הצגת שם המסעדה** כדי להסתיר את השם לצד הלוגו ב־Apple. ב־Google שם התוכנית ממשיך להופיע. אם בחירת התמונה נכשלה, קראו את ההודעה שמתחת לשדה. בחרו **שמירת טיוטה**. אם עורך אחר שמר גרסה חדשה יותר, טענו אותה מחדש לפני ניסיון נוסף.

## שימוש בעיצוב האתר בכרטיס ה־Wallet

ב־**לקוחות ← תוכנית הנאמנות ← סטודיו Wallet**, בחרו **צור עם AI**. המערכת משתמשת בצבעי האתר שפורסם, בלוגו ובתמונה אחת לבאנר. תחילה נבדקת התמונה הראשית בדף הבית, אחר כך תמונת הנושא או תמונה ממקטע גלוי. אם לא הוגדר צבע באתר, אפשר לחלץ צבע מהלוגו או מהתמונה. המסגור מותאם לכל Wallet. בדקו את התצוגות של Apple ושל Google. אפשר לבטל מיד את ההצעה, לשנות צבעים או לשנות את מסגור הבאנר. רכיב שאינו זמין שומר על ערכו הקיים. שמירת הטיוטה שומרת את העיצוב למסעדה. פרסום העיצוב מחיל אותו על כרטיסי הלקוחות.

<span id="try-card-layouts" />

## השוואת תבניות עם הבאנר של המסעדה

בסטודיו Wallet בחרו פלטת צבעים או ערכו את שני הצבעים. לאחר הוספת באנר נסו תצוגת מוצר שלם, פנורמה או יתרה על התמונה. כל תבנית משתמשת בתמונה שלכם. לאחר מכן אפשר לדייק את המסגור ל־Apple ול־Google. הזיזו את מחוון היתרה לדוגמה כדי לבדוק את הקריאות בשתי התצוגות. המחוון משפיע רק על ההדמיה. שמרו טיוטה, בדקו כרטיס ניסיון ופרסמו את העיצוב כשהוא מוכן.

<span id="apple-test" />

## הוספת כרטיס בדיקה ל־iPhone

בעיצוב השמור בחרו **יצירת כרטיס בדיקה של Apple** ואז **הורדת קובץ ‎.pkpass**. פתחו את הקובץ ב־iPhone ובחרו **הוספה**. בדקו את הלוגו, תמונת הכותרת, הצבעים ואת הכיתוב כרטיס בדיקה. הכרטיס מציג התקדמות להמחשה וקוד QR לדוגמה. אם החתימה אינה זמינה, בדקו את הגדרות החתימה של Apple בסביבה הנוכחית. הלשונית Google מציגה את העיצוב בתצוגה מקדימה. בדקו שהכיתוב מופעל על ידי Foody מופיע ליד קוד ה־QR. פתחו את פרטי הכרטיס כדי לעבור לקישור ל־Foody.

<span id="publish-design" />

## פרסום עיצוב הכרטיס ושיתוף קישור הצטרפות

הפעילו את תוכנית המועדון של מסעדת הפיילוט. תחת **כרטיס ללקוחות**, בחרו **פרסום עיצוב הכרטיס** כדי להחיל את העיצוב השמור. פרסמו שינויים נוספים כשהם מוכנים. בחרו **העתקת קישור להצטרפות** כדי לשתף את דף המועדון של המסעדה. אם יש התנגשות, טענו מחדש את הסטודיו ובדקו את העיצוב השמור.

<span id="member-card" />

## הצטרפות, הוספת כרטיס אישי ובדיקת צבירה

בטלפון, פתחו את קישור ההצטרפות, התחברו, אשרו את התנאים והצטרפו. ב־iPhone בחרו **הוספת הכרטיס ל־Apple Wallet** ואז **הוספה** ב־Wallet. כאשר Google זמין, כפתור **הוספה ל־Google Wallet** פותח את Google לצורך אישור. הורידו שוב מהחשבון ובדקו את קוד ה־QR ואת ההתקדמות. בצעו הזמנת בדיקה מזכה ושלמו מאותו חשבון. בדקו שההתקדמות בכרטיס תואמת לדף המועדון. בפיילוט קופה שבו מופעלים זיהוי ומכירות מועדון, סרקו את קוד ה־QR האישי ושייכו את החבר לפני אישור התשלום. בהגעה לסף, בדקו את ההטבה באזור המועדון ונסו לממש אותה בתהליך תשלום שהופעל.

## עיצוב כרטיס ידני

ב־**סטודיו Wallet ← עיצוב הכרטיס** בחרו **מחברת שולחן** לתמונה עם רצועת משבצות או **כרזת קפה** לתמונה גזורה לפני גל. העלו לוגו ותמונה או בחרו **שימוש בלוגו האתר** ו־**שימוש בתמונת האתר** כדי לבחור אותם מהאתר שפורסם. פתחו **כותרת העיצוב** לעריכת הטקסט, הגופן, הגודל, המיקום והזווית. ב־**דוגמה ורקע** הגדירו צבעים, דוגמה ומיקום לקו ההפרדה. ב־**מיקום התמונה** אפשר להזיז את התמונה, לחתוך שוליים שקופים ולהציג אותה לפני הכותרת. ב־**לוגו ופרטי החברות** בחרו יתרה בלבד או יתרה ויעד, ואת היתרה לצבירה או ההטבה של התוכנית. השוו בין תצוגת הכרזה והכרטיס הקלאסי של Apple ופתחו את Google Wallet. באייפון תצוגת הכרזה זמינה מ־iOS 27. שנו את יתרת ההדגמה כדי לדמות התקדמות. שמרו טיוטה, בדקו את כרטיס Apple ופרסמו את העיצוב כדי להחיל אותו על כרטיסי הלקוחות.

## יצירת כרטיס חותמות

ב־**לקוחות ← תוכנית נאמנות** בחרו צבירה לפי ביקורים והגדירו כמה ביקורים מזכים בהטבה. פתחו את **סטודיו Wallet** והפעילו **כרטיס חותמות**. תחת **סמל לביקורים שנותרו** בחרו ספל קפה, קרואסון, המבורגר, משולש פיצה, סושי, פיתה עם פלאפל, בייגל, שיפוד, קערת ראמן, סלט, גלידה, עוגייה, קוקטייל או כוכב. כל ביקור שנצבר מסומן בסימן וי. בחרו צבע לרקע החותמת וצבע לסמל, והגדירו שלוש עד שש חותמות בשורה. אפשר להשתמש בתמונת המסעדה כרקע. הזיזו את יתרת ההדגמה ל־7 כדי לבדוק כרטיס של עשרה ביקורים בשתי התצוגות. שמרו את הטיוטה והורידו כרטיס בדיקה של Apple עם יתרת ההדגמה. פרסמו את העיצוב כדי להחיל אותו על כרטיסי החברים. בביקור המזכה העשירי מונפקת הטבה ונפתח מחזור חדש באותו הכרטיס. ביעד גדול שתי השורות מציגות את קבוצת הביקורים הנוכחית והמונה מציג את ההתקדמות הכוללת.

## שיתוף קוד ההצטרפות וסריקת כרטיס חבר

ב־**סטודיו Wallet ← כרטיס לקוח** פתחו את קוד ההצטרפות והורידו את קובץ ה־SVG להצגה בקופה. הלקוח סורק, מתחבר לחשבון שלו באתר המסעדה, מאשר את התנאים ומוסיף את הכרטיס האישי לארנק הזמין. הזמנה מקוונת או משלוח המקושרים לאותו חשבון מזכים עם תשלום העומד בתנאים. בקופה פתחו את הנאמנות בחשבון לפני התשלום ובחרו **סריקה במצלמה** באייפון, באייפד או באנדרואיד, או השתמשו בקורא דו־ממדי. הציגו בכל פעם קוד של חבר אחד ובדקו את הכרטיס לפני שיוכו לחשבון. חיפוש חבר מציג את היתרה. הביקור נצבר עם התשלום המזכה.
