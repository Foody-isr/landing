Internal Foody operators: Menu, Combos, Ingredient icons and POS login screen.

<span id="catalog" />

## Maintain shared catalog resources

Review global versus restaurant-owned context before editing a catalog or combo resource. Confirm references before deletion. Shared library changes can affect many restaurants and require explicit impact review.

<span id="icons" />

## Generate and review ingredient icons

Search existing icons before generation. Review the generated asset, labels and suitability before saving or editing. Remove only the intended unused resource. Do not describe an AI image as a real customer/product photograph.

<span id="login-slides" />

## Maintain login slides

Edit localized eyebrow, slide text and images, then order and activate the intended slides. Preview every language and confirm image rights. Login marketing content must not claim an unavailable feature or unapproved offer.
