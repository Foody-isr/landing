# Dispatch desktop help review

The dispatch guide shipped with this release is `delivery/dispatch-and-routes` in French, Hebrew and English. Its **Read the dispatch board**, **Insert a delivery into a planned route**, and departure-review procedures also cover the full-width manager workspace.

The panel headed with the courier's name contains the street, city, sequence and arrival window. Selecting the address or a map marker opens the same details and correction action. The desktop can open the first address needing attention immediately. Moving the search into the list and the route details underneath the map leaves the documented day picker, filters, correction, insertion and departure workflows accessible by their existing labels. A selected stop can be reviewed when the map is hidden. The Foody link in the header returns to the restaurant dashboard, and the existing links switch delivery modules. The courier workspace keeps its own navigation.

The three published procedures and the support assistant share the same text for these actions. This layout revision adds no separate step to the published instructions. The release's current help inventory records the new layout stylesheet and updated component sources.
