# Proposed title

feat: clarify Foody restaurant scope and add a sourced Tabit comparison

# Proposed description

Foody's restaurant positioning did not clearly connect its iPad/Android POS,
staff-interface languages and kitchen tools to the questions prospective buyers
ask. This clarifies the home/restaurant/POS copy in French, Hebrew and English,
adds a native-feature comparison with per-row Foody evidence and three explicitly
synthetic examples, and links the localized routes through the site and sitemap.

Tabit absence labels are visibly attributed to Foody's assessment and have not
been independently confirmed; third-party integrations are outside that native
scope. The 3% arithmetic is hypothetical and is not a published Tabit tariff.
Existing plan prices/exclusions and the current help release/corpus are retained.
The included six-response visibility pilot predates publication and does not
claim a ranking improvement. Directory messages remain unsent drafts.

Validation: 47 help tests, lint, TypeScript, a 414-page production build, exact
help/source contract checks and the 50-page marketing smoke suite. Chromium checks
cover FR/HE/EN desktop/mobile, the three example interactions, zero-stock/reset
behavior, RTL and two no-JavaScript comparisons. The added CI smoke step reuses
the existing build and was exercised locally, including startup and cleanup.
