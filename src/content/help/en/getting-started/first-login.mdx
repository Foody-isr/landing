Admin sign-in and account menu

<span id="activate" />

## Activate an invitation

Open the invitation received by email, check the restaurant, choose your password and confirm your contact details. A POS code is requested only when the assigned restaurant permissions allow taking orders (orders.manage) or managing payments (payments.manage). A courier with the usual read-only delivery role, or a kitchen-only role, finishes without this step. A role name alone does not determine the requirement. Never share a password or POS code.

<span id="restaurant" />

## Select the restaurant

Sign in with your own account, then choose an authorized restaurant. Check its name before editing or exporting data.

<span id="recover" />

## Recover access

After a rejected POS code or failed save, reopen the same still-valid email link and retry; failed activation does not consume it. A duplicate code message means a POS operator must choose a different 4–6 digit code. A courier without POS permissions does not need to try more combinations. If the link is expired, lacks restaurant context or says it was already used and activation did not finish, ask a staff manager to open Staff → Employees → the member → Resend setup invitation. Use the newest email; resending invalidates previous unused links without recreating the member. If activation already succeeded, sign in with the password you chose, or use password recovery. Removed restaurant access must be reviewed by the manager. Never share activation links or credentials with the assistant.

<span id="end-pos-shift" />

## End a POS shift safely

On an enrolled POS, choose End shift. If Foody reports an open cash drawer, use the offered shortcut to More → Reports → Cash drawer balance. Count and close the drawer on that same device, then retry End shift. A Verifone terminal deposit is separate. If cash or payment confirmation is uncertain, ask an authorized manager to reconcile it before ending the shift; do not bypass the guard by logging out another way.
