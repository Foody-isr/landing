Use the search entry in the Admin navigation for the currently selected restaurant.

<span id="search" />

## Find a business record

Open search, enter a sufficiently specific term and review grouped item, order, customer and stock results. Use arrows and Enter to open, or Escape to close. Results respect the current restaurant and permissions; an empty result is not proof the record never existed.

<span id="lists" />

## Filter and inspect a list

Use the page’s search, filters, date range, column chooser and pagination where available. Open the row/action menu for its permitted operations. Check active filters before treating a missing record as deleted. Transactions is a separate Admin sidebar destination for confirmed payments; the global search groups items, orders, customers and stock, but is not a payment-history search.

<span id="carte-series-stock" />

## Find the item-stock overview

Predefined item stocks now have a journal under Items & menus → Stock history and on each product. A rotating carte can prepare initial allowances per series and publish them without restoring already committed units. Previous remaining counts are not carried forward. Order changes and pre-production releases use the original frozen pool; a produced item remains consumed. Ingredient/preparation quantities and recipe costs remain separate. See [Availability](/en/help/kitchen/availability) for initial imports, corrections and history filters.
