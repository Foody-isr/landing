Admin → Settings → Security

<span id="enrol" />

## Add a passkey

Open security settings on a compatible browser and register a passkey using the device prompt. Verify it appears in your account list.

<span id="use" />

## Sign in with a passkey

Use the passkey sign-in option and complete the browser/device verification. A device unlock does not grant restaurant permissions you do not already hold.

<span id="remove" />

## Remove an unused key

Select an unused passkey in security settings and confirm removal. Keep a working sign-in method before removing your last key.

## If the operation fails

If the device prompt fails, keep the existing key and use another configured sign-in method.
