Admin → Clients → Promotions

<span id="create" />

## Create a promotion

Create the discount code and choose fixed amount or percentage. Review its value, eligible scope, minimum basket and validity dates before saving.

<span id="limits" />

## Set usage limits

Set the available usage/customer restrictions and active state. Check the restaurant timezone when scheduling a start or end date.

<span id="verify" />

## Verify the guest result

Test an eligible basket in the agreed test environment. Verify the discount line and final total; a rejected code should explain the applicable restriction.
