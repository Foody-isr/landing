## Create the catalogue

In **Menu → Items**, create or edit the items you sell. Set the name, base price and relevant options. Categories are internal catalogue/reporting labels. A category does not make an item appear online.

<span id="section-2" />

## Make an item visible

1. Open the menu you want to offer in **Menu → Menus**.
2. Create or choose a group inside that menu.
3. Add the item to the group. The same item can appear in several groups or menus.
4. Check the menu and group channels: web for online ordering, POS for staff.
5. Check opening/custom hours, item availability and stock-related restrictions.
6. Verify the result in the intended guest website or POS channel.

If an item is missing online, start with its group membership and web channel. Do not solve it by creating duplicate catalogue items.
