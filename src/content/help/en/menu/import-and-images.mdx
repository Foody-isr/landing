Admin → Articles → import / item image controls

<span id="input" />

## Choose the source

Choose an offered file, image, text or website import. Use material you may upload; extraction availability depends on enabled AI/upload services.

<span id="review" />

## Review extracted items

Review names, prices, categories, variants and options before accepting. Resolve duplicates and incomplete fields; extraction is a draft, not a verified menu.

<span id="commit" />

## Save and place in groups

Confirm the reviewed import once, inspect the created catalogue and add items to the required menu groups/channels. Category membership alone does not publish items.

<span id="images" />

## Upload or generate an image

Use the item image controls, review the preview and explicitly accept the image. Check food accuracy and framing before using a generated illustration publicly.
