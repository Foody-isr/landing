Admin → Settings → Restaurant → Order journey

<span id="approval" />

## Review order acceptance

Choose the restaurant’s acceptance policy and review which orders require staff approval. Paid and accepted are distinct statuses; unpaid online orders requiring payment are not sent as paid POS orders.

<span id="kitchen" />

## Configure kitchen progression

Review automatic/manual kitchen sending and preparation progression. Test one intended order in the agreed test environment and verify its kitchen ticket.

<span id="clock" />

## Set preparation timing

Set the preparation delay/start policy and splitting behavior in the offered controls. Check minute-level values and timezone; guest scheduling is validated by the API.

<span id="save" />

## Verify saved settings

Save changes, reopen the settings and verify the POS behavior. Resolve a save error before expecting other devices to use the draft.

<span id="whatsapp-notifications" />

## Enable customer messages for a stage

First save the approved template and activate notifications in Settings → Communications → WhatsApp. In Settings → Restaurant → Order journey choose the service, expand the stage, review its automatic event, set Notify the customer to Yes, then select Message type and WhatsApp template/language. Delivery reminder templates offer stage-entry or day-before delivery with a time. Save each service journey explicitly. See the [complete WhatsApp trigger procedure](/en/help/communications/templates-and-automation#stage), including prerequisites, default templates and message history. Saving does not send to previous orders.
