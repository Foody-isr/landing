Admin → Settings → Restaurant → Processing / Workflow

<span id="approval" />

## Review order acceptance

Choose the restaurant’s acceptance policy and review which orders require staff approval. Paid and accepted are distinct statuses; unpaid online orders requiring payment are not sent as paid POS orders.

<span id="kitchen" />

## Configure kitchen progression

Review automatic/manual kitchen sending and preparation progression. Test one intended order in the agreed test environment and verify its kitchen ticket.

<span id="clock" />

## Set preparation timing

Set the preparation delay/start policy and splitting behavior in the offered controls. Check minute-level values and timezone; guest scheduling is validated by the API.

<span id="save" />

## Verify saved settings

Save changes, reopen the settings and verify the POS behavior for each intended order type. The response must confirm the fields you changed, including kitchen sending and prepayment. A successful HTTP response with missing or old values is not a confirmed save: the editor keeps your draft and displays the save error. Correct or reload the settings before expecting other devices to use them; do not repeat an order or payment to test a settings save.

<span id="whatsapp-stage-attachment" />

## Choose a stage attachment

In Admin, open Settings → Restaurant → Order workflow and the required pickup or delivery stage. With Notify customer enabled, choose the message type, an approved Meta photo/PDF model and its attachment: a fixed file, or that order’s receipt for a PDF. Choose the sending time and save the workflow. Manual stage entry or its configured event uses this binding. Selecting a file changes neither progression, payment rules nor delivery eligibility. Correct an incompatible or missing model/file before relying on delivery. The model library and creation controls are in Settings → Communications → WhatsApp.

<span id="meta-template-image-preview" />

## WhatsApp template image

Approved WhatsApp Utility templates with a photo automatically use the image retrieved from Meta when no local file was selected. The preview displays that image; a change before a manual send requires another review. Retrieval failure blocks sending without a text-only fallback. Configure or refresh the template in Settings → Communications → WhatsApp. See the [WhatsApp guide](../communications/whatsapp#meta-template-image-sync).
