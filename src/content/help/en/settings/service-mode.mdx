Admin → Settings → Devices → Modes

<span id="mode" />

## Choose a mode profile

Review the available mode profiles and select the one intended for the POS device. Check enabled modules and the device assignment before use.

<span id="service" />

## Configure table and counter behavior

Review seating, covers, service courses, kitchen sending and return-to-menu behavior in the corresponding POS settings. Save and verify on the intended device.

<span id="fulfillment" />

## Keep fulfillment independent

Configure the restaurant's [fulfillment methods and prompt](/en/help/settings/pos-behavior#fulfillment-methods) separately from the table layout and device mode profile. The whole-check method determines its overall service; an item choice is a preparation exception and does not create a separate delivery. Review [whole-check and item choices](/en/help/orders/order-types#pos-whole-check) before changing a sale. A payment does not hide an order from Orders → All or automatically mark its preparation complete.
