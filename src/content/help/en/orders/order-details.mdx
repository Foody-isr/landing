Admin → Orders → select an order

## Availability and access

Order changes require orders.manage; read access alone does not permit edits.

<span id="filter" />

## Find the right order

Choose order/date basis, status and fulfillment filters. Open the order and verify number, customer, service date and payment status before acting.

<span id="create" />

## Create a staff order

Use New order, select items/options and fill the required contact and fulfillment fields. Review the total and submit once; check the created order before retrying an uncertain result.

<span id="edit" />

## Edit saved details

Use the available edit action to change customer, address or fulfillment details. Save and reread the order; review preparation, fees and date restrictions before changing an existing schedule.

<span id="status" />

## Accept, prepare and hand over

Use only the next status actions offered for the order. Verify acceptance, kitchen, ready and handover results separately from payment. Check consequences before rejection or cancellation.

<span id="communications" />

## Send customer messages deliberately

Open customer messages to inspect attempts and delivery evidence. Preview a recap/reminder before sending; an uncertain send must be checked, not repeated automatically.

<span id="payment-links-invoices" />

## Collect a balance and open Sumit invoices

Open the order payment summary. A Partially paid order with a positive Balance due offers Generate payment link, as does a paid order increased after editing. This collection action requires order-management permission and is hidden on cancelled orders. Generating or sharing does not settle the balance. See [payment links and balances](/en/help/payments/payment-links-and-balance) for the full initial/partial-payment steps. If a Sumit document is recorded, Actions → View invoice opens its existing PDF and any supplementary documents; see [Sumit invoices](/en/help/payments/sumit-invoices) for download, email and sharing.
