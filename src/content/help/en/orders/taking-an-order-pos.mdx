POS → Tables / Order entry

<span id="start" />

## Start the intended check

Choose the table or counter order and verify the active check, service and employee. Existing separated checks retain their own balances.

<span id="add" />

## Add and customize items

Choose a visible POS menu group, item, active variant and allowed modifiers. Review quantity, notes and price before adding. Required choices must be completed.

<span id="seat-course" />

## Assign seats and courses

Where enabled, assign the item to a seat, shared table or course before sending. These preparation assignments are distinct from later financial bill splitting.

<span id="send" />

## Send and verify preparation

Review pending items and use the configured kitchen-send action. Check the saved order and kitchen result; printer success and order persistence are separate outcomes.

<span id="resume" />

## Resume or collect payment

Reopen the saved check to add items or start payment. Confirm the selected check and unpaid balance before charging; do not resend already-sent food.

<span id="whatsapp-stage-attachment" />

## Choose a stage attachment

In Admin, open Settings → Restaurant → Order workflow and the required pickup or delivery stage. With Notify customer enabled, choose the message type, an approved Meta photo/PDF model and its attachment: a fixed file, or that order’s receipt for a PDF. Choose the sending time and save the workflow. Manual stage entry or its configured event uses this binding. Selecting a file changes neither progression, payment rules nor delivery eligibility. Correct an incompatible or missing model/file before relying on delivery. The model library and creation controls are in Settings → Communications → WhatsApp.
