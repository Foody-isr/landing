## Starting an Order

### Table Mode
1. On the home screen, go to the **Tables** tab.
2. Tap an available table on the floor plan (or table list).
3. An order session opens for that table.

### Counter Mode
1. Go to the **POS** tab.
2. Select the order type: **Pickup** or **Delivery**.
3. Optionally enter the customer's name or phone number.

---

## Adding Items

1. Browse categories on the left panel.
2. Tap an item to add it to the cart (right panel).
3. To add the same item multiple times, tap it again or use **+** in the cart.

### Applying Modifiers
If an item has required modifiers, the modifier panel opens automatically. For optional modifiers, tap the item in the cart.

1. Select the desired options.
2. Tap **Confirm**.

The item in the cart shows a summary of chosen options and any price adjustments.

---

## Sending to the Kitchen

Once the order is ready to be prepared:

1. Tap **Send to Kitchen** at the bottom of the cart.
2. The order is transmitted to the kitchen queue.
3. In **Table Mode**, the table status updates to show an active order.

> **Auto Send to Kitchen**: If this setting is enabled in Workflow Settings, orders are sent automatically when confirmed; no manual step needed.

---

## Adding Items to an Existing Order

If a customer wants to add more items after the initial order is sent:

1. Tap the table (or find the order in the Orders tab).
2. Add the new items.
3. Tap **Send to Kitchen** again; only the new items are sent as an additional ticket.

---

## Viewing and Managing Orders

Go to the **Orders** tab in FoodyPOS to see all active orders sorted by status:
- **Pending**: placed but not yet sent to kitchen
- **In Kitchen**: sent to kitchen, being prepared
- **Ready**: kitchen marked it as done
- **Served / Paid**: closed

In **FoodyAdmin → Orders**, managers can see the full order history with filters by date, status, and order type.
