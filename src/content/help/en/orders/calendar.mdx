Admin → Restaurant calendar

<span id="browse" />

## Inspect a date

Select the calendar period and the relevant service/date. Review the scheduled entries and restaurant timezone before making an exception.

<span id="exceptions" />

## Add or edit an exception

Use the date’s offered exception controls, set the affected service/hours and save. Review the calendar result and the corresponding guest availability.

<span id="remove" />

## Remove an obsolete exception

Review the affected date before removing an exception. Confirm that normal scheduling now applies; existing orders still need individual review if their fulfillment changed.
