## Opening a Table

1. From the home screen, tap the **Floor Plan** tab.
2. Tap an available table (shown in green).
3. Enter the number of guests using the number pad.
4. Tap **Open Table** to begin the session.

The table will turn yellow to indicate it is occupied and has an active session.

## Table Status Colors

| Color | Status |
|-------|--------|
| Green | Available |
| Yellow | Occupied — order in progress |
| Orange | Order sent to kitchen |
| Red | Bill requested |

## Moving Guests

To move guests from one table to another:

1. Open the occupied table.
2. Tap **Actions → Move Table**.
3. Select the destination table.
4. Confirm the move.

All items in the cart are transferred to the new table.
