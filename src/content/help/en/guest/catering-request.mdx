Open the catering service on the restaurant’s website.

<span id="request" />

## Complete a catering flow

Select the active service/offer and complete guest count, date/time, choices and contact details. Review the calculated total and whether approval or deposit is required. Submit once and retain the private quote link. A quote awaiting approval is not final acceptance.

<span id="contact-phone" />

## Enter a valid contact phone

Before submitting an order or catering request, enter a complete phone number. In checkout Contact and payment, the initial calling code follows the restaurant country: +33 for France, +972 for Israel, and so on. Choose another calling code for a foreign number, or paste an international number starting with +. Catering assumes Israel for local numbers; foreign numbers need + and their country code. Spaces, dashes and parentheses are accepted; the saved value is international, for example +972502345678. Incomplete numbers, invalid prefixes, letters and extensions block submission and require correction. Phone remains optional for table orders where the form permits it; a supplied number must be valid. Format validation does not check WhatsApp registration. Any SMS verification code still follows the restaurant setting.

<span id="contact-phone-format" />

## Check the contact phone number

Enter a complete number with its country code. Foody’s phone check removes spaces and invisible clipboard formatting before validation; it does not correct digits or accept letters or extensions. If your form still rejects a pasted number, retype it in international format and check the digits before continuing. An accepted format does not confirm ownership or the existence of a WhatsApp account. Any SMS verification and other order requirements still apply.
