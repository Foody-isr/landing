Admin → Settings → Restaurant → Floor plans / Table QR

<span id="plan" />

## Create a floor plan

Create a named floor plan, add the required tables and arrange their position, shape and capacity using the editor. Save before opening it on the POS.

<span id="sections" />

## Organize service sections

Review restaurant sections and table assignments. Keep table identities stable when rearranging a plan; moving a drawing is different from moving a financial check.

<span id="qr" />

## Prepare table QR cards

Open table QR settings, select the intended table and customize the available card style/text. Download or print the offered output and scan it to verify restaurant and table.

<span id="live" />

## Use the live table view

Select the correct floor plan on the POS and inspect table status before opening a check. Review covers/seats separately and confirm the saved check before payment or transfer. Selecting a table after changing a draft's fulfillment method is not a bill move or merge. A table with an existing financial check refuses and cancels that pending transfer, keeping the source draft intact; see [changing a draft's service](/en/help/orders/order-types#pos-change-draft).

<span id="mobile-terminal" />

## Use Checks on mobile

On the updated mobile POS, Checks opens the floor plan directly. Tap the room name beside Floor to switch rooms; search opens the searchable list and Close returns to the plan. Restaurant-authored positions, shapes, states and table access remain authoritative; pan or zoom when needed. Open a free table and choose the guest count or No covers. Back cancels the selection. The + button offers the counter sale, access to open checks and Actions; Actions retains staff filters, To do and Refresh. Permissions and restaurant settings determine available functions.
