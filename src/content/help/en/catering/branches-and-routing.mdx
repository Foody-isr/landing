Open Catering → Branches and Routing.

<span id="branches" />

## Maintain eligible branches

Create or edit the branch’s available fields and active state. Check its restaurant ownership and service associations. An inactive branch should not be used as a new customer destination.

<span id="rules" />

## Set routing rules

Create/edit a rule using the offered service, destination and conditions. Review priority/order and conflicts before saving. Check a representative request against the rules, and confirm before deleting a rule that existing workflows rely on.
