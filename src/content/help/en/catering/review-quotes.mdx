Open Catering → Quotes and select the request. Review its current status and full configuration.

<span id="review" />

## Approve or reject a quote

Check customer request, event date, guests, selections, calculated total and deposit status. If permitted adjust the total and add a note, then approve or reject explicitly. Confirm the saved status; a request awaiting review is not an accepted event.

<span id="deposit" />

## Review deposit and refund evidence

Distinguish the primary deposit from a recorded duplicate charge. If Refund is available, select the intended target and amount and confirm once. For an external refund, first complete it in the provider console, then record its required reference in Foody. Recording an external refund does not itself move money. An uncertain provider result requires review before retrying.
