Open Website, then Site design. Work in the draft and preview both desktop and mobile before publishing.

<span id="theme" />

## Choose a theme and colors

Select the theme, brand color and color style. Use custom background, text, muted, accent and divider colors where offered. Check text contrast on every background. A section override affects that section; site settings provide inherited defaults.

<span id="fonts" />

## Set fonts and text roles

Choose the font pairing or heading/body fonts. For ordering, adjust category title, item name, description and price roles separately. Check Hebrew direction and long names; a desktop size may need a separate mobile setting.

<span id="images" />

## Frame item images

Choose fit, crop and focal point in the image controls. Compare the card and item detail preview on both screen sizes. Keep text outside image assets when it needs translation. Save the draft, then publish only after checking the public page.

<span id="mobile-fulfillment-review" />

## Review mobile order entry

When the invitation is enabled, on mobile and desktop, review the initial Sign in and Continue as a guest choices as text actions without an additional yellow button. No address field or confirmation should appear before choosing. Check opening/closing sign-in and guest access: address entry for Delivery, collection details without a delivery address for Pickup. Back must retain the draft; switching services or reopening the dialog must not repeat the guest choice. Also check a signed-in customer’s validated address card and Edit. In a 360 px visual viewport with at least four results, four whole 44 px suggestions must remain visible. The title, tabs, Back and input keep their positions when the keyboard opens or closes. Check 320 px screens, desktop and French, Hebrew and English. Sign in opens Google and the email/password form. Facebook and Apple appear only when configured by the service. Standalone email-code sign-in is no longer offered. Account creation, address verification and password-recovery codes remain separate. Check dismissal and resumption without losing the draft on mobile and desktop; four whole suggestions with the keyboard open retain the same geometry. Sign-in choices must not reintroduce moving tabs or input.

<span id="related-service-controls" />

## Access the new controls

The entry sign-in invitation is controlled in Website → Order journey → Show the sign-in invitation on arrival. Off goes directly to pickup/delivery details; when on, Order without an account remains immediately visible. Save the draft and publish to apply this choice. See [the journey setting](/en/help/website-qr/checkout-and-receipt#optional-entry-sign-in). When the invitation is off, a discreet Sign in link remains available in the pickup or delivery dialog. It opens authentication only when selected; dismissing authentication retains entered details and allows ordering without an account.
