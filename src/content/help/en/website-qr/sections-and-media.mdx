Open a content or landing page, select a section in the canvas or sidebar, and use its content, appearance and animation panels.

<span id="structure" />

## Add, move and hide sections

Add an available section type, edit it, and reorder it on the page. Visibility hides the section without deleting its content. Moving a section to another page changes its location. Review the draft before confirming deletion.

<span id="content" />

## Write and select content

Edit headings, subtitle, body and button links for text/image, hero, feature cards and supporting content. Choose the items or menu groups for menu highlights and featured items. Contact sections can show address, phone, hours and social links. Check each language rather than embedding untranslated text in pictures.

<span id="media" />

## Set images and video

Upload or select media, adjust fit, overlay, background, width, height and spacing where available. For video choose controls, autoplay, loop and muted state. Browsers can restrict autoplay; check the actual mobile page and retain readable text while media loads.

<span id="campaign-hero" />

## Create a campaign hero carousel

This layout requires the compatible Website and Admin release. Select a Hero section and choose Campaign under Layout. Open Slides, add up to six slides and use the up/down controls to set their order. For each slide, select a photo or video, add image alternative text and edit the title, subtitle, button text/link and background. Choose Show the whole image to keep a whole cup or product, or Fill the panel; check the resulting crop on both screen sizes. The rounded panels can show a glimpse of the next slide. Autoplay is off by default; if enabled, set the slide duration from 5 to 30 seconds. Previous/next remain available; play/pause stays visible when autoplay is enabled. To adjust panels and hide controls for a manual presentation, see [carousel layout controls](/en/help/website-qr/sections-and-media#campaign-layout-controls). Editor preview stays static. Automatic progression and video pause during hover, focus, dragging, when the section is offscreen or the tab is hidden. Reduced motion prevents automation until an explicit play action. Review keyboard use and both motion preferences. Browser restrictions can prevent automatic video playback. Keep essential information and the order link readable without motion. Wait for draft saving and publish only after checking every slide; if the public view is unsupported, confirm the matching Website release before publishing.

<span id="campaign-layout-controls" />

## Adjust carousel panels and controls

These controls require compatible Website and Admin versions. In the Campaign hero, open Carousel layout, then set panel width separately for desktop and mobile, from 70 to 100%, then set panel spacing from 0 to 64 px. The active slide stays centered; the selected width determines how much of neighboring slides is visible. Use Navigation controls alignment to choose left, center or right. Use responsive default spacing restores spacing suited to each screen size. You can hide the counter and playback control for a manual presentation. When autoplay is enabled, play/pause remains visible even if its display is switched off. With both autoplay and playback controls off, videos stay on their poster image; the arrows still change slides. Review both screen sizes, keyboard use, reduced motion and every medium before publication.

<span id="campaign-featured-grid" />

## Set the featured product grid

On a compatible release, select the featured-items section, open Layout and color, and choose Campaign under Card presentation. Set the desktop columns and Mobile columns separately; Pink Coffee starts with four columns on desktop and two on mobile. Set the image background and optional alternating image background, then review the rounded image cards, names, descriptions, prices and order buttons. Choose actual catalogue items; the presentation does not create menu visibility or bypass availability, required sizes and modifiers. Check that selecting an item opens the correct item and retains its choices. If an item is absent, review its active status, menu-group membership and channel before changing the design. In manual selection, Select all visible products adds the current filtered results; review the selection and order, then confirm. Clear selection empties that list in the picker. The grid places items across multiple rows. Grid content width sets its maximum width from 640 to 1,800 px; Space between rows sets vertical spacing from 0 to 100 px. Under Individual product backgrounds, choose Product and its Image background: it overrides the shared or alternating background for that product only. Use shared or alternating background restores that background for the selected product only. Each image’s framing and zoom remain editable. Names, descriptions, prices and buttons stay independently configurable. These settings do not change catalogue items, prices or options.

<span id="motion" />

## Preview animation

Enable motion only where useful. Set entrance, duration, delay, replay, hover and parallax; mobile motion can have separate settings. For rotating text/carousels set phrases, interval and transition speed. Test reduced-motion behavior and avoid motion that hides essential information.

<span id="mobile-fulfillment-review" />

## Review mobile order entry

When the invitation is enabled, on mobile and desktop, verify that Order without an account is immediately visible and usable, with Sign in as an option. No address field or confirmation should appear before choosing. Check opening/closing sign-in and guest access: address entry for Delivery, collection details without a delivery address for Pickup. Back must retain the draft; switching services or reopening the dialog must not repeat the guest choice. Also check a signed-in customer’s validated address card and Edit. In a 360 px visual viewport with at least four results, four whole 44 px suggestions must remain visible. The title, tabs, Back and input keep their positions when the keyboard opens or closes. Check 320 px screens, desktop and French, Hebrew and English. Sign in opens Google and the email/password form. Facebook and Apple appear only when configured by the service. Standalone email-code sign-in is no longer offered. Account creation, address verification and password-recovery codes remain separate. Check dismissal and resumption without losing the draft on mobile and desktop; four whole suggestions with the keyboard open retain the same geometry. Sign-in choices must not reintroduce moving tabs or input.

<span id="related-service-controls" />

## Access the new controls

The entry sign-in invitation is controlled in Website → Order journey → Show the sign-in invitation on arrival. Off goes directly to pickup/delivery details; when on, Order without an account remains immediately visible. Save the draft and publish to apply this choice. See [the journey setting](/en/help/website-qr/checkout-and-receipt#optional-entry-sign-in). When the invitation is off, a discreet Sign in link remains available in the pickup or delivery dialog. It opens authentication only when selected; dismissing authentication retains entered details and allows ordering without an account.

<span id="featured-variant-choices" />

## Keep featured item choices

When adding a featured item, complete each required variant position. Moving to the menu and cart preserves these choices separately from modifiers, at the selected format price.
