Select the header or footer in the Website editor. These site-wide regions are distinct from a page section.

<span id="header" />

## Configure the header

Choose logo, name visibility, logo size/position and link alignment. Compare transparent/overlay and scrolled/solid states, including their separate text colors and optional scrolled logo. Preview the mobile hamburger menu.

<span id="links" />

## Manage links and the main button

Add or edit a navigation link, choose its destination and order. Enable the main button if needed; set its label, link, shape, size and appearance in both header states. Open each destination in preview. A link alone does not publish an unpublished page.

<span id="footer" />

## Configure footer content

Choose layout and visibility, then select logo, description, address, phone, opening hours and social links to display. Edit custom text and the Foody branding options separately. Use valid public social/contact links and check them after publishing.

<span id="mobile-fulfillment-review" />

## Review mobile order entry

Before publishing a site release, open its order page on a small phone. Check Pickup and Delivery, then enter an address with the keyboard open: the field, scrolling suggestions and top close button must remain reachable; confirmation stays visible and enables after a complete selection and checks. Select a complete address, check that the keyboard dismisses and delivery and time checks finish before confirmation. Account access remains optional. Check French, Hebrew and English using the restaurant colors. Publish the updated procedure with the site correction. On mobile, opening or dismissing the keyboard keeps the same layout: Pickup and Delivery tabs stay visible, the field keeps its position and suggestions scroll in their own area. The cover is reserved for larger screens. Sign in remains accessible as a compact link beside confirmation. Google Maps attribution and errors stay visible.
