Select the header or footer in the Website editor. These site-wide regions are distinct from a page section.

<span id="header" />

## Configure the header

Choose logo, name visibility, logo size/position and link alignment. Compare transparent/overlay and scrolled/solid states, including their separate text colors and optional scrolled logo. Preview the mobile hamburger menu.

<span id="links" />

## Manage links and the main button

Add or edit a navigation link, choose its destination and order. Enable the main button if needed; set its label, link, shape, size and appearance in both header states. Open each destination in preview. A link alone does not publish an unpublished page.

<span id="footer" />

## Configure footer content

Choose layout and visibility, then select logo, description, address, phone, opening hours and social links to display. Edit custom text and the Foody branding options separately. Use valid public social/contact links and check them after publishing.

<span id="mobile-fulfillment-review" />

## Review mobile order entry

On mobile and desktop, review the initial Sign in and Continue as a guest choices as text actions without an additional yellow button. No address field or confirmation should appear before choosing. Check opening/closing sign-in and guest access: address entry for Delivery, collection details without a delivery address for Pickup. Back must retain the draft; switching services or reopening the dialog must not repeat the guest choice. Also check a signed-in customer’s validated address card and Edit. In a 360 px visual viewport with at least four results, four whole 44 px suggestions must remain visible. The title, tabs, Back and input keep their positions when the keyboard opens or closes. Check 320 px screens, desktop and French, Hebrew and English. Sign in opens Google and the email/password form. Facebook and Apple appear only when configured by the service. Standalone email-code sign-in is no longer offered. Account creation, address verification and password-recovery codes remain separate. Check dismissal and resumption without losing the draft on mobile and desktop; four whole suggestions with the keyboard open retain the same geometry. Sign-in choices must not reintroduce moving tabs or input.

<span id="related-service-controls" />

## Access the new controls

The entry sign-in invitation is controlled in Website → Order journey → Offer sign-in before ordering. Off goes directly to pickup/delivery details; when on, Order without an account remains immediately visible. Save the draft and publish to apply this choice. See [the journey setting](/en/help/website-qr/checkout-and-receipt#optional-entry-sign-in).
