In Website choose the order page and switch between page and item-detail surfaces. Catalog data remains managed in Menu.

<span id="menu-layout" />

## Choose menu layout and navigation

Select the displayed menu and desktop/mobile layout. Configure group banners, category navigation, prices and descriptions with the available controls. Menu groups control public ordering structure; internal categories do not create public sections.

<span id="item-surface" />

## Customize item details

Select the item-detail preview to edit cover image and display options. Test a real configured item with variants, required modifiers, quantities and notes. Design changes do not change its base price, modifier deltas, stock or ordering eligibility.

<span id="discovery" />

## Place discovery content

Edit discovery heading, image position, card height/radius and panel colors. Choose its placement relative to the menu/group or after a number of items where supported. Preview empty and populated groups on mobile before publication.
