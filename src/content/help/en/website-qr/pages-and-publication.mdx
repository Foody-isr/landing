Open Website and the page list. Page settings are staged in the draft before public publication.

<span id="create" />

## Add a page

Choose Add page, preview a library template or select an available page type, name it and choose whether to add it to navigation. Review the public address and menu/service association for commerce pages. Reserved or duplicate addresses are rejected. Confirm creation to add it to the draft.

<span id="identity" />

## Edit page identity and navigation

Open Page settings → General. Change name, editable address, navigation inclusion and menu association where offered. Some special commerce addresses cannot be edited. Check links to a changed address and do not assume old external links redirect automatically. A mobile navigation link follows a page address change. After deleting a page, choose another destination or hide the entry before publishing.

The home page selected in Website pages applies to the browser. Set the installed app opening screen in [Mobile experience → App home](/en/help/website-qr/navigation-and-footer#app-home).

<span id="seo" />

## Set search and sharing metadata

In **SEO**, set the title and description and inspect the search preview. In **Social**, choose a page image to use when the site share image is empty. Save the staged settings and verify the public link after publication. Search engines and messaging apps refresh their previews on their own schedule.

<span id="site-share-image" />

## Set up the site’s share image for WhatsApp

With compatible Admin and Web versions, open **Site design → Site settings → Share image**. Upload one image for the restaurant and publish the draft. The published image is used on site, menu, item, receipt, confirmation and order tracking links. A page image in **Social** and automatic item images serve as fallbacks when the site share image is empty. Use **SEO** for each page’s title and description.

Choose **Centered logo on a background** for transparent artwork and pick a contrasting **Preview background**. **Brand color** can use the default site style. For a **Full-frame image**, keep important elements inside the center square of the 1200 × 630 frame. Paste a public link in WhatsApp and check the thumbnail. The app may display a cached preview while it refreshes.

<span id="publish" />

## Publish and verify the draft

Preview desktop/mobile, public navigation, commerce availability and links, then Publish deliberately. Reopen the public page to verify the result. Unsaved/staged changes are not evidence of public publication. Review page references before a confirmed deletion and use discard/reset only for changes you intend to abandon.
