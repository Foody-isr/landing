Open Website and the page list. Page settings are staged in the draft before public publication.

<span id="create" />

## Add a page

Choose Add page, preview a library template or select an available page type, name it and choose whether to add it to navigation. Review the public address and menu/service association for commerce pages. Reserved or duplicate addresses are rejected. Confirm creation to add it to the draft.

<span id="identity" />

## Edit page identity and navigation

Open Page settings → General. Change name, editable address, navigation inclusion and menu association where offered. Some special commerce addresses cannot be edited. Check links to a changed address and do not assume old external links redirect automatically.

<span id="seo" />

## Set search and sharing metadata

In SEO set title and description and inspect the search preview. In Social choose or remove the sharing image and review the preview. Save the staged settings and verify each public language after publication. Search engines and messaging caches control when their previews refresh.

<span id="publish" />

## Publish and verify the draft

Preview desktop/mobile, public navigation, commerce availability and links, then Publish deliberately. Reopen the public page to verify the result. Unsaved/staged changes are not evidence of public publication. Review page references before a confirmed deletion and use discard/reset only for changes you intend to abandon.
