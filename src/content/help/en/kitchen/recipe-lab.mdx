Admin → Kitchen → Lab

<span id="start" />

## Start or import a recipe

Choose manual entry, text import or an offered AI brief. Define the dish/objective, stock policy and relevant quantities before creating a draft.

<span id="ingredients" />

## Validate ingredient links

Review recipe components, existing/new stock and preparations. Resolve unit conversions and estimated prices; an estimated price is not a confirmed supplier purchase cost.

<span id="refine" />

## Refine and review cost

Use the refinement panel to propose changes, then inspect the recipe tree and cost summary. Verify preparation steps and image proposals before accepting them.

<span id="commit" />

## Commit a reviewed version

Select the intended menu item and commit only a validated draft. Use version history to inspect saved versions; check an uncertain commit before submitting it again.
