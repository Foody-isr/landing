## Modifier la recherche sur le site

Dans l’éditeur du site, ouvrez le formulaire de livraison. Activez **Autocomplétion des adresses** pour proposer les adresses Google, ou désactivez-la pour laisser les clients saisir leur adresse. Publiez la modification pour l’appliquer au site de commande. Vos zones de livraison et leurs tarifs restent ceux configurés dans Livraisons.
