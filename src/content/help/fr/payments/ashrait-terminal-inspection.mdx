## Consulter la dernière transaction du terminal

Sur la version compatible, ouvrez Plus → Paramètres → Matériel → Terminaux de paiement. Sur iPad, la consultation concerne le terminal associé actuellement actif ; sur un Victa Portable reconnu dans l’inventaire, elle concerne cet appareil. Le terminal doit déjà être connecté. Avec le droit de gérer les paiements, ouvrez Dernière transaction du terminal puis appuyez sur Consulter la dernière transaction. Ouvrir la fenêtre ne lance aucune requête. La consultation affiche uniquement la référence, le type, le résultat communiqué et le montant lorsqu’ils sont disponibles. Une préautorisation reste distincte d’un achat ; aucun paiement ni aucune addition n’est modifié. Aucun reçu ni donnée de carte n’est affiché. Une réponse vide, notamment après redémarrage, ne prouve pas l’absence d’un paiement. Si un paiement ou dépôt doit être vérifié, reprenez son parcours d’origine : la consultation ne lève aucun verrou et ne relance aucune opération. Après un changement de compte, de restaurant, de droit ou de terminal, consultez à nouveau ; l’ancien résultat n’est pas réutilisé. Si les champs du terminal sont incomplets, Foody lit les détails disponibles sur le reçu Ashrait portant la même référence. Une information manquante ou contradictoire reste « Non confirmé ». Comparez la référence à celle de la vente dans Transactions ; ne relancez pas un paiement sur la seule base de cet écran.

Lorsqu’un paiement carte est en attente dans Foody, le responsable peut consulter le terminal d’origine s’il est connecté, identifié et disponible. L’écran affiche la dernière transaction connue de ce terminal. Faites confirmer le résultat de la tentative d’origine si cette lecture est vide ou concerne une autre vente. Après avoir résolu la tentative, les copies sont proposées selon les données disponibles.

## Capacités des rapports Ashrait en Israël

Sur la version compatible avec Ashrait Israël, les anciennes actions génériques Consulter les totaux, Clôturer uniquement et Transmettre uniquement sont retirées. Pour la fin de journée, utilisez le parcours Solde en caisse et sa transmission explicite du terminal. Les ventes enregistrées dans Foody ne sont pas les totaux bancaires du terminal. Si Ashrait confirme le dépôt sans fournir de chiffres ou de référence de lot, ces informations restent indisponibles : elles ne valent pas zéro. Les autres commandes décrites dans une documentation prestataire ne sont pas nécessairement proposées dans Foody. Faites vérifier leur disponibilité et la procédure par un responsable et Verifone avant toute opération de maintenance ou financière avancée.

## Reprendre un paiement Ashrait interrompu

Si la réponse du terminal est perdue, ouvrez l’addition sur la caisse d’origine avec le même terminal connecté. Choisissez Payer, Carte puis Vérifier le paiement carte. Cette action reprend la tentative existante sans débiter à nouveau. Si Foody confirme que la tentative s’est arrêtée avant l’encaissement, qu’elle a été refusée ou annulée, vous pouvez recommencer. Une autorisation correspondante est enregistrée sur l’addition d’origine. Si le terminal renvoie une réponse vide ou différente, communiquez la référence affichée à un responsable pour consulter le journal Verifone. Le résultat reste à confirmer avant un nouvel encaissement de cette addition. Une autre caisse équipée d’un autre terminal peut encaisser une autre addition.

## Imprimer le reçu carte du terminal

Consultez la dernière transaction et comparez sa référence à celle de la vente. Si le terminal a fourni une copie exploitable, choisissez « Imprimer le reçu carte » pour le client ou « Imprimer le reçu carte commerçant ». Foody utilise l’imprimante intégrée sur le Victa Portable et l’Epson de reçus sélectionnée sur l’iPad associé au Victa Mini. Le numéro de carte est masqué. Après confirmation de l’impression, « Imprimer une autre copie » imprime le même document. Si le résultat reste incertain, vérifiez le papier avant toute nouvelle demande. Ces actions impriment uniquement une copie de la transaction consultée, sans nouveau paiement ni transmission SHVA.
