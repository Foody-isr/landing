Ouvrez Paramètres → Modèles de messages, modèles WhatsApp ou Workflow selon le canal.

<span id="template" />

## Créer et vérifier un modèle

Modifiez textes localisés et variables, ou soumettez un modèle WhatsApp Utility via le prestataire. Vérifiez approbation, langue et ordre des variables. La suppression peut être bloquée même si l’étape qui le référence est désactivée.

<span id="stage" />

## Associer les messages aux étapes

Choisissez un modèle approuvé sur l’étape et son déclenchement. Les messages concernent les futures entrées, sans reprise historique. Rappels livraison exigent données livreur/date ; satisfaction exige remise enregistrée. Lisez le déclencheur, sans supposer un envoi systématique la veille.

<span id="media-binding" />

## Associer le fichier à la notification

Après approbation, ouvrez Configurer sur le message dans WhatsApp, ou Prévenir le client dans Paramètres → Restaurant → Parcours des commandes. Choisissez le modèle avec photo/PDF, puis son fichier fixe dans la bibliothèque de cet établissement, ou Reçu de cette commande pour un modèle PDF. Enregistrez la page ou le parcours ; Terminé ferme uniquement le panneau de configuration des messages généraux. Le déclencheur et l’horaire restent ceux choisis dans le parcours. Le reçu Foody est généré à partir des articles et montants enregistrés pour cette commande ; il ne remplace pas la facture fiscale. Vérifiez l’aperçu du message et du fichier avant un envoi manuel. Une pièce jointe est envoyée par message, via Meta direct activé ; ces contrôles ne configurent pas les pièces jointes Twilio.
