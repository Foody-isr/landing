Connexion Admin et menu du compte

<span id="activate" />

## Activer une invitation

Ouvrez l’invitation reçue par e-mail, vérifiez le restaurant, choisissez votre mot de passe et confirmez vos coordonnées. Le code caisse est demandé uniquement si les permissions affectées dans ce restaurant permettent la prise de commande (orders.manage) ou la gestion des paiements (payments.manage). Un livreur avec les droits habituels de consultation, ou un rôle limité à la cuisine, termine sans cette étape. Le nom du rôle ne détermine pas à lui seul cette obligation. Ne partagez jamais de mot de passe ni de code caisse.

<span id="restaurant" />

## Sélectionner le restaurant

Connectez-vous avec votre compte puis choisissez un restaurant autorisé. Vérifiez son nom avant toute modification ou export.

<span id="recover" />

## Récupérer l’accès

Après un refus de code caisse ou un échec d’enregistrement, rouvrez le même lien e-mail encore valide et réessayez ; une activation échouée ne le consomme pas. Un code déjà utilisé impose à l’utilisateur de la caisse de choisir un autre code de 4 à 6 chiffres. Un livreur sans droits caisse n’a pas à essayer d’autres combinaisons. Si le lien a expiré, ne permet pas d’identifier le restaurant ou indique avoir déjà été utilisé alors que l’activation n’a pas abouti, demandez à un responsable autorisé d’ouvrir Personnel → Employés → le membre → Renvoyer l’invitation de configuration. Utilisez le dernier e-mail reçu ; le renvoi invalide les anciens liens inutilisés sans recréer le membre. Si l’activation a déjà réussi, connectez-vous avec le mot de passe choisi ou utilisez la récupération de mot de passe. Un accès retiré doit être vérifié par le responsable. Ne partagez jamais de lien d’activation ni d’identifiants avec l’assistant.

<span id="end-pos-shift" />

## Terminer un shift de caisse en sécurité

Sur un POS autorisé, choisissez Terminer le shift. Si Foody signale une caisse ouverte, suivez le raccourci Plus → Rapports → Solde en caisse. Comptez et clôturez la caisse sur ce même appareil, puis réessayez de terminer le shift. Le dépôt Verifone est distinct. Si les espèces ou un paiement restent incertains, demandez le rapprochement à un responsable autorisé avant de terminer le shift ; ne contournez pas le blocage par une autre déconnexion.
