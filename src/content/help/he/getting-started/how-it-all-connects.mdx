## התמונה הגדולה

שישה חלקים עובדים יחד. ברגע שמבינים את השרשרת, הכול מתחבר:

- **מלאי** — חומרי הגלם שאתם קונים (עגבניות, טונה, שמן, לחמניות).
- **הכנות** — מה שאתם מייצרים מהמלאי באצוות (רוטב, בצק, מרינדה).
- **מתכון** — מה שמנה אחת משתמשת בו: המרכיבים וההכנות שלה, עם כמויות.
- **פריט (מנה)** — מנה בתפריט שלכם, המוצגת ללקוחות בתוך קבוצת תפריט.
- **זמינות** — מחושבת מהמתכון + המלאי הנוכחי: מלאי נמוך או אזל, אוטומטית.
- **עלות מזון** — גם היא מחושבת מהמתכון.

הזרימה:

```
מלאי   ┐
       ├─→  מתכון  ─→  פריט  ─→  מוצג ללקוחות
הכנות  ┘                │
                        ├─→  זמינות   (נמוך / אזל, אוטומטי)
                        └─→  עלות מזון (רווח למנה)

הזמנה מתבצעת  ─→  המתכון מנוכה מהמלאי  ─→  הזמינות מתעדכנת
```

מנה אינה אי בודד: היא מצביעה על מתכון, המתכון מצביע על המלאי וההכנות, והקישור הזה לבדו גורם
ל**זמינות** ול**עלות המזון** לעבוד מעצמן.

## הגדירו בסדר הזה

### 1. הוסיפו את המרכיבים שלכם למלאי
הזינו את חומרי הגלם שאתם קונים, עם היחידה והכמות הנוכחית.
→ [ניהול מלאי](/he/help/kitchen/stock-management)

### 2. (אופציונלי) בנו את ההכנות שלכם
אם אתם מכינים רטבים, בצקים או בסיסים באצוות, הגדירו אותם פעם אחת והשתמשו בהם במנות שונות.
ייצור אצווה מזכה מלאי; מנות שמשתמשות בו חוזרות אוטומטית.
→ [הכנות](/he/help/kitchen/preparations)

### 3. צרו את הפריטים שלכם
הוסיפו כל מנה לקטלוג (שם, מחיר, תמונה, קטגוריה).
→ [יצירת פריט בתפריט](/he/help/menu/creating-a-menu-item)

### 4. תנו לכל פריט מתכון
בלשונית **מתכון** של הפריט, קשרו את המרכיבים וההכנות שמנה אחת משתמשת בהם, עם כמויות.
**זה הקישור שמפעיל את כל השאר.** מנה ללא מתכון תמיד זמינה ואין לה עלות מחושבת.
→ [מרכיבים ומנות](/he/help/menu/ingredients-and-portions)

### 5. שימו פריטים בקבוצת תפריט
פריטים מופיעים ללקוחות רק לאחר שהם בקבוצת תפריט.
→ [קטגוריות ופריטים](/he/help/menu/categories-and-items)

### 6. הזמינות עובדת עכשיו מעצמה
עם מתכונים מוגדרים, מנות עוברות ל**מלאי נמוך** ול**אזל** אוטומטית ככל שהמלאי יורד, וחוזרות
כשמחדשים מלאי. כווננו עם כללים, או דרסו מנה בודדת.
→ [זמינות](/he/help/kitchen/availability)

## מה מקבלים כשהשרשרת מחוברת

- **אזל אוטומטי** — לא צריך יותר לכבות מנות ידנית כשמרכיב אוזל.
- **עלות מזון מדויקת** — הרווח למנה, מחושב מהמתכון.
- **מלאי שמתעדכן לבד** — כל הזמנה מנכה את המתכון שלה, והמספרים נשארים נכונים.
- **מקום אחד לשנות** — שנו את מתכון ההכנה פעם אחת וכל המנות מתעדכנות.
