## קריאת הנחות בהזמנות ששולמו

בדוח מכירות הקופה, הנחות (הזמנות ששולמו) כוללות רק הנחות בהזמנות ששולמו בתקופה. מכירות ברוטו לפי כלל הספירה בלוח הבקרה עשויות לכלול גם הזמנות שהתקבלו וטרם שולמו. אין להפחית בין הכרטיסים כדי לחשב נטו: מכירות נטו, זיכויים ועמלות אינם זמינים כאן.

<span id="pos-sales-report" />

## קריאת מכירות בקופה

עם analytics.view פתחו עוד ← דוחות ← מכירות. בטאבלט עמודת הצד מציגה את הסעיפים המותרים; בטלפון פתחו אותם מתוך דוחות. בחרו היום, שבוע, חודש, רבעון או שנה. כל תקופה קלנדרית מתחילה בתחילתה ומסתיימת היום; השבוע מתחיל ביום שני. יום הייחוס מגיע מהמסעדה ולא משעון הטלפון. הדוח משתמש במסעדה הנוכחית, בתאריכי יצירת הזמנות ובכלל ההזמנות הנספרות שהוגדר בלוח הבקרה. הסכומים לבדם אינם מוכיחים גבייה בנקאית. רענון טוען מחדש בלי לרשום תשלום.

בדקו ברוטו, מספר מכירות, מכירה ממוצעת, הנחות, תרשים ואמצעי תשלום שנרשמו. הרחיבו פריט לווריאציות האמיתיות שלו או קטגוריה לפריטיה. פריטים וקטגוריות מבוססים על שורות ששולמו עם חלוקת ארוחות מורכבות; משלוח והנחות עשויים להסביר הבדל מסכומי ההזמנות. מקף במכירות נטו, זיכויים או עמלות מציין שהנתון אינו מסופק לתקופה ולא שהוא אפס. רעננו טעינה שנכשלה במקום לפרשה כיום ללא מכירות. הדוח אינו סוגר מזומן פיזי או אצוות כרטיסי Verifone.

<span id="section-1" />

## התחילו במסך הבית

פתחו את **הבית** ב-FoodyAdmin. לוח הבקרה מציג את התקופה או השירות שנבחרו, הזמנות לטיפול, מכירות ברוטו, מספר הזמנות, הזמנה ממוצעת, פריטים שנמכרו והזמנות אחרונות. הגישה תלויה בהרשאות שלכם.

<span id="section-2" />

## בדיקת בסיס התאריך

בורר התאריכים מאפשר שימוש בתאריך ההזמנה או בשירות/סדרה מתוכננים. שירות עתידי יכול לכלול הזמנות שכבר התקבלו עבורו; הנתונים אינם מעידים שהשירות הסתיים. בדקו את בסיס התאריך לפני השוואה לדוח אחר.

האפשרות של ההזמנות הנספרות מציינת את שיטת החישוב, למשל הזמנות ששולמו או התקבלו. מכירות לפי הזמנות שהתקבלו אינן הוכחה שכל התשלומים נגבו. בדקו בנפרד תשלומים שדורשים טיפול.

<span id="section-3" />

## השוואות ונתונים חסרים

השוואה דורשת תקופה או שירות קודמים זמינים. בשירות עתידי או מתמשך לוח הבקרה מסביר מדוע השוואה אינה מוצגת. נתון שאינו זמין שונה מתקופה ריקה; רעננו או פתרו את שגיאת הטעינה לפני פירוש ערך חסר כאפס.

<span id="section-4" />

## דוחות מפורטים

פתחו **דוחות** כדי להציג את המסכים המותרים לתפקיד שלכם. בחרו תקופה ובדקו את המסננים. בסקירה קיימת פעולת ייצוא; ודאו שהתאריכים ושיטת החישוב תואמים לניתוח הרצוי.
