המדריך הזה מלווה התקנה של **Epson TM-U220IIB-i** מפתיחת הקרטון ועד לפתק
הראשון שנשלח מ-Foody. לאחר שרשת המסעדה מוכנה, הקצו כ-20 עד 30 דקות למדפסת.

> **בדקו את הדגם המדויק לפני שמתחילים.** מדפסת שמתחברת ישירות ל-Foody צריכה להיות
> הגרסה החכמה **TM-U220IIB-i**, וב-TMNet WebConfig צריך להופיע **Server Direct Print**.
> בדגם TM-U220IIB רגיל עם USB או Ethernet אין שירות תשאול מובנה. במקרה כזה יש
> לחבר אותה דרך מדפסת Epson חכמה תואמת שמוגדרת כשער. אם התפריט אינו מופיע,
> עצרו ושלחו ל-Foody צילום של מדבקת הדגם.

## מה צריך

- המדפסת וספק הכוח של Epson.
- קסטת סרט תואמת וגליל נייר ברוחב 76 מ״מ.
- כבל Ethernet המחובר לנתב או למתג של המסעדה.
- מחשב או iPad המחוברים לאותה רשת בזמן ההתקנה.
- חשבון **בעלים** או **מנהל** ב-FoodyAdmin עם הרשאה לניהול מדפסות.
- מומלץ לשמור את כתובת ה-IP של המדפסת בנתב כדי שיהיה קל להגיע ל-WebConfig.

אל תחברו את המדפסת לרשת אורחים. רשתות כאלה מבודדות לעתים קרובות בין המכשירים.
Foody אינה דורשת פתיחת פורט נכנס במסעדה; המדפסת יוצרת חיבור HTTPS יוצא ל-Foody.

## 1. פתחו את האריזה ובדקו את הציוד

1. הוציאו את המדפסת, ספק הכוח, כבל החשמל וקסטת הסרט.
2. הסירו את כל הספוגים, סרטי ההדבקה וחומרי ההגנה.
3. בדקו את המדבקה מתחת או מאחורי המדפסת. רשמו את הדגם המדויק, המספר הסידורי
   וכתובת ה-MAC.
4. הציבו את המדפסת הרחק מהתזות, אדים ומקורות חום, עם מקום לפתיחת שני המכסים.
5. השאירו את המדפסת כבויה בזמן חיבור הכבלים.

## 2. התקינו את הסרט והנייר

### קסטת הסרט

1. כאשר המדפסת כבויה, פתחו את מכסה הסרט.
2. מתחו את הסרט בסיבוב עדין של החוגה בכיוון המסומן.
3. הניחו את הקסטה ישר ולחצו עד שתתיישב במקומה.
4. סגרו את המכסה ללא כוח.

ראש ההדפסה עלול להיות חם מאוד לאחר שימוש. אל תגעו בו ואל תזיזו את עגלת הסרט בכוח.

### גליל הנייר

1. פתחו את מכסה הנייר בעזרת הידית.
2. הכניסו את הגליל בכיוון המסומן בתוך המכסה. הנייר צריך להשתחרר ללא מתח.
3. משכו כמה סנטימטרים של נייר ישר החוצה.
4. סגרו את המכסה לגמרי וקרעו את העודף בפס הקריעה.

## 3. חברו את המדפסת לרשת

1. חברו כבל Ethernet בין המדפסת לנתב או למתג.
2. חברו את ספק הכוח של Epson למדפסת ולאחר מכן לשקע יציב.
3. הדליקו והמתינו שנורת השגיאה תכבה.
4. הדפיסו דף מצב רשת בעזרת לחצן המצב של ממשק ה-Ethernet. מיקומו תלוי בממשק המותקן;
   אל תשתמשו בלחצן האיפוס.
5. אתרו את כתובת ה-**IPv4**, לדוגמה `192.168.1.48`.

אם הכתובת היא `0.0.0.0` או חסרה, בדקו את הכבל ואת יציאת המתג. כתובת שמתחילה ב-`169.254`
מציינת שהנתב לא סיפק כתובת.

## 4. פתחו את Epson TMNet WebConfig

1. מהמחשב או ה-iPad שבאותה רשת, פתחו `https://IP-ADDRESS`. אם HTTPS עדיין לא פעיל במכשיר,
   השתמשו ב-`http://IP-ADDRESS` רק להגדרה מקומית זו.
2. אם מופיעה אזהרת תעודה מקומית, המשיכו רק לאחר בדיקה שה-IP זהה לזה שבדף המצב.
3. היכנסו עם פרטי מנהל המופיעים על תווית המוצר או בתיעוד שסופק עם המדפסת. שנו את סיסמת ברירת המחדל.
4. שמרו את הכתובת בנתב, או בקשו ממנהל הרשת להגדיר כתובת סטטית מתאימה.

כתובת ה-IP משמשת רק לניהול מקומי. **לא מזינים אותה ב-Foody**, כי Server Direct Print משתמש
בחיבור יוצא מהמדפסת לענן.

## 5. רשמו את המדפסת ב-FoodyAdmin

פתחו **FoodyAdmin ← הגדרות ← מדפסות**, ולחצו על **רישום מדפסת**.

| שדה | ערך מומלץ |
|---|---|
| שם | המיקום הפיזי: `מטבח`, `פס פיצה`, `בר 1` או `בר 2` |
| יצרן | `Epson Server Direct Print` |
| דגם | הדגם המדויק, לדוגמה `TM-U220IIB-i` |
| שער Epson | **ישיר** אם מדפסת זו פונה ל-Foody; אחרת בחרו בשער Epson הרשום |
| מזהה WebConfig | מזהה ייחודי, למשל `restaurant-kitchen-01` |
| מזהה התקן | `local_printer` במצב ישיר; מזהה ה-WebConfig המדויק במצב שער |
| רוחב | `TM-U220 · 76 mm · 384 dots` |
| מרווח | `2 s` |
| עמדה | בחרו עמדה קיימת או צרו עמדה בשם המיקום הפיזי |

לחצו על **רישום**. Foody מציגה לפעם אחת את כתובת Server Direct Print, כתובת הודעת המצב,
מזהה WebConfig, סיסמה ו-Digest realm. השאירו את המסך פתוח. הסיסמה לא תוצג שוב לאחר הסגירה.

## 6. הגדירו Server Direct Print ב-WebConfig

ב-TMNet WebConfig פתחו **Server Direct Print** והפעילו אותו. העתיקו במדויק את הערכים ש-Foody יצרה:

1. **Server Direct Print URL**: כתובת ההדפסה שמוצגת ב-Foody.
2. **ID / User ID**: מזהה WebConfig שנבחר ב-FoodyAdmin.
3. **Password**: הסיסמה החד-פעמית.
4. **Device ID**: `local_printer` למדפסת המובנית, או מזהה ההתקן המדויק שנרשם מאחורי שער.
5. **Interval**: שתי שניות.

הפעילו את **Status Notification** והזינו את כתובת המצב של Foody עם אותם פרטי התחברות. שמרו והחילו
את ההגדרה, ואפשרו למדפסת להפעיל את עצמה מחדש אם תתבקשו. אל תוסיפו רווחים למזהה, לסיסמה או
לכתובות. כתובות Foody צריכות להישאר ב-`https://`.

## 7. המתינו למצב מקוון והדפיסו בדיקה

1. חזרו ל-**הגדרות ← מדפסות**.
2. המתינו עד 15 שניות. המצב אמור לעבור מ-**לא ידוע** ל-**מקוון**, וזמן הקשר האחרון יתעדכן.
3. לחצו על **בדיקה** או **הדפסת פתק בדיקה**.
4. המתינו ליציאה המלאה של הפתק. Foody מסמנת אותו כמודפס רק לאחר אישור מה-Epson.
5. בדקו את שם העמדה, תווים בעברית ובצרפתית, הזנת הנייר והקריאות.

אם המצב נשאר **לא ידוע**, המדפסת עדיין אינה מגיעה ל-Foody. אם היא **מקוונת** אך הבדיקה נכשלת,
פתחו את **משימות** כדי לראות את שגיאת המכשיר האחרונה.

## 8. צרו עמדות ייצור

עמדה היא יעד לוגי. מרכיבי התפריט מנותבים לעמדה, והעמדה מחזיקה את המדפסת. כך אפשר להחליף מדפסת
תקולה בלי לשנות את כל התפריט.

| עמדה | מדפסת ראשית | תוכן טיפוסי |
|---|---|---|
| מטבח | Epson במטבח | מנות חמות, מנות ראשונות וטיגונים |
| פס פיצה | Epson בפיצה | פיצות ותוספות לפיצה |
| בר 1 | Epson הראשונה בבר | משקאות וקוקטיילים |
| בר 2 | Epson השנייה בבר | עותק שני של המשקאות אם שני הברים מייצרים |

השתמשו ב-**עותק הזמנה מלא** למשלח שצריך לראות את כל ההזמנה. **מדפסת גיבוי** אינה יוצרת עותק נוסף;
היא נכנסת לפעולה רק כשהראשית לא זמינה. כדי להדפיס בשתי מדפסות הבר, צרו שתי עמדות ונתבו את המשקאות לשתיהן.

## 9. נתבו קטגוריות וחריגות

פתחו את **ניתוב**:

1. סמנו את כל העמדות שצריכות לקבל כל קטגוריה.
2. לדוגמה, נתבו `פיצות` ל-**פס פיצה** ו-`משקאות` ל-**בר 1** ו-**בר 2**.
3. שמרו את המטריצה.
4. הוסיפו חריגת פריט רק אם פריט צריך לעזוב את ניתוב הקטגוריה שלו.
5. הוסיפו חריגת תוספת לרכיב שמיוצר בנפרד, למשל רוטב שנשלח למטבח כאשר המנה העיקרית נשלחת לגריל.

לפני הפעלת הדפסת השרת, לוח ההתקנה צריך להראות שכל המדפסות נבדקו, לכל עמדה הוקצתה מדפסת וכל הקטגוריות מנותבות.

## 10. הוציאו פתק אמיתי מ-Foody

1. הפעילו **הדפסת פתקי מטבח מהשרת**.
2. ב-FoodyPOS צרו הזמנת בדיקה שכוללת פריט מכל קטגוריה מנותבת ותוספת עם ניתוב מיוחד.
3. אשרו או שלחו את ההזמנה למטבח לפי זרימת העבודה של המסעדה.
4. ודאו שכל עמדה מקבלת רק את השורות שלה, ושעמדה עם עותק מלא מקבלת את כל ההזמנה.
5. ב-FoodyAdmin פתחו **משימות**. כל פתק צריך לעבור מ-**בתור** ל-**ממתין לאישור**, ולבסוף ל-**הודפס**.

אל תתחילו שירות חי לפני שהבדיקה המלאה הזאת עברה. השאירו את שיטת ההדפסה הקודמת זמינה בהזמנה החיה הראשונה.

## פתרון תקלות מהיר

| תסמין | מה לבדוק |
|---|---|
| אין נורת רשת | כבל Ethernet, יציאת המתג וחשמל |
| כתובת `169.254.x.x` | שרת ה-DHCP של הנתב לא ענה |
| WebConfig לא נפתח | אותה רשת, IP נכון ובידוד אורחים כבוי |
| Server Direct Print חסר | דגם שאינו חכם או קושחה/ממשק לא תואמים |
| מצב לא ידוע ב-Foody | שירות כבוי, URL/מזהה/סיסמה שגויים או DNS/אינטרנט חסומים |
| מקוון אך אין פתק הזמנה | עמדה ללא מדפסת, קטגוריה ללא ניתוב או הדפסת שרת כבויה |
| משימה נכשלה | פתחו **משימות**, תקנו שגיאת נייר/מכסה/סרט והריצו בדיקה נוספת |
| עמדה שגויה | בדקו את מטריצת הקטגוריות ואת חריגות הפריט/תוספת |
